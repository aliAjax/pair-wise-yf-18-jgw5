# hxyfront-62006 珠宝镶嵌宝石分拣

源提示词编号：8

面向珠宝镶嵌工作室的宝石分拣工作台：按订单与批次录入宝石，跟踪从分拣、缺陷确认到镶嵌的全过程。

## 功能

- **批次录入**：录入宝石编号、种类、形状、克拉重量、净度、颜色、切工、尺寸、镶嵌位置和缺陷备注，记录归入当前订单的当前批次
- **编号唯一**：同一订单内一个编号只能进入一个批次，重复录入时提示该编号原来所在的批次
- **待确认区**：含缺陷备注的宝石先留在待确认区，确认无误后转为待镶嵌，之后可标记已镶嵌
- **尺寸筛选**：按 ＜4mm / 4–6mm / ＞6mm 分档，仅作用于当前批次的宝石清单
- **实时统计**：总克拉、待镶嵌、待确认数量随记录与状态更新，并在订单清单中按订单汇总
- **镶嵌位置示意图**：高亮当前批次各镶嵌位置（主石位 / 围石 / 副石位 / 戒臂）的宝石分布
- **本地持久化**：全部数据保存在浏览器 localStorage，关掉页面再回来可继续分拣
