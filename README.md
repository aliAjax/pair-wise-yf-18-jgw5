# hxyfront-62006 珠宝镶嵌宝石分拣

源提示词编号：8

面向珠宝镶嵌工作室的宝石分拣工作台，可按订单与分拣批次记录宝石。

## 功能

- 按批次录入宝石：编号、种类、形状、克拉、净度、颜色、切工、尺寸、镶嵌位置、缺陷备注
- 数据通过 localStorage 持久化，关闭页面再回来可继续分拣
- 同一订单内一个编号只能进入一个批次；重复录入会提示该编号原来的批次
- 含缺陷备注的宝石自动进入待确认区，确认无缺陷后才可完成镶嵌
- 尺寸筛选（≤3 / 3–5 / 5–8 / >8 mm）只作用于当前批次
- 总克拉、待镶嵌、待确认数量随录入和状态变更实时更新，并在订单清单中按订单显示
- 镶嵌位置示意图按位置汇总各状态宝石数量

## 技术栈

React + Vite + TypeScript
